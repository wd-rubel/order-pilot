All-in-one WooCommerce operations toolkit: multi-courier shipping, fraud detection, Meta Pixel & Conversions API tracking.

== Description ==

Order Pilot streamlines your WooCommerce fulfillment and marketing workflows in a single, modern interface.

* Multi-courier booking (Pathao, SteadFast, RedX)
* Automated courier status synchronization
* Fraud detection & customer verification
* Meta Pixel & CAPI tracking with deduplication
* Real-time analytics dashboard

== Installation ==

1. Upload the `order-pilot` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure your couriers and tracking in the Order Pilot dashboard.
